# Recipes

A tiny static recipe list. No dependencies.

- `npm start` serves it on http://127.0.0.1:8080 (`PORT` changes the port); any path without a file extension gets
  `index.html`.
- `npm test` runs the tests in `test/` with `node --test`.

## Files

- `app.js`
- `recipes.js`
- `serve.js`
- `index.html`
- `style.css`
- `package.json`
- `README.md`
- `test/recipes.test.js`
- `scripts/check-docs.js`
- `.ultimate/settings.json`
